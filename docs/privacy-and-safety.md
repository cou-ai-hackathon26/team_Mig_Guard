# Privacy, Safety, and Ethics Policy

## 1. Zero Document Storage
- Uploaded job offer letters, recruiter chat screenshots, and pasted text are processed strictly in memory and discarded immediately after analysis[cite: 2].
- No user images, extracted text, or personal records are saved to any database or disk storage[cite: 2].

## 2. PII Masking & API Key Security
- Passport numbers and personal phone numbers are masked before sending data to any external vision or language model API.
- All API keys live strictly in backend environment variables; the frontend never holds or exposes keys.

## 3. Never-Says-Safe Principle
- **Mig_Guard never labels a job offer "safe."**
- The lowest-risk verdict is **"Fewer concerns found — still verify with official authorities"**[cite: 2].
- Missing, blurry, or unreadable fields are explicitly reported under **Unverifiable**, never treated as low risk.

## 4. Risk Guidance Disclaimer & Helplines
- Mig_Guard provides pre-departure risk guidance based on deterministic rules and public circulars, not formal legal advice[cite: 2].
- Every result screen displays official Bangladeshi government and migrant-support helpline numbers.
